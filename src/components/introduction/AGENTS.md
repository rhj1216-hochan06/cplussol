# AGENTS.md

> `src/components/introduction` 작업 규칙

## 1. 역할

- 회사소개와 주요 고객 섹션을 담당한다.
- 콘텐츠 성격은 텍스트보다 이미지 중심이다.

## 2. 수정 규칙

- 새 소개 자료는 우선 `public/images/intrduction` 또는 관련 자산 위치를 확인한 뒤 연결한다.
- 회사소개 섹션은 이미지 흐름이 끊기지 않도록 순서와 크기를 함께 점검한다.
- 주요 고객 섹션은 단일 대표 이미지 구성이므로 비율 깨짐 여부를 먼저 확인한다.

## 3. 반응형 규칙

- 모바일과 데스크톱에서 이미지 폭 처리 방식이 다를 수 있다.
- 큰 이미지 교체 시 모바일 스크롤 길이와 가독성을 함께 확인한다.
