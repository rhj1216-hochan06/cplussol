# AGENTS.md

> `src/components` 공통 작업 규칙

## 1. 디렉터리 역할

- `main`: 헤더, 푸터, 전역 네비게이션
- `category`: 제품 목록, 검색, 페이지네이션
- `detail`: HTML형 제품 상세 콘텐츠
- `introduction`: 회사소개와 주요 고객 섹션
- `map`: Kakao 지도 렌더링

## 2. 컴포넌트 작성 원칙

- 가능한 한 표현용 컴포넌트로 유지한다.
- 데이터 로딩은 이미 상위 페이지 또는 해당 영역 대표 컴포넌트에서 처리하는 패턴을 따른다.
- 새 공통 훅이나 유틸은 반복 로직이 명확할 때만 도입한다.

## 3. 자산과 링크 규칙

- 정적 이미지 경로는 기존처럼 `/images/...` 절대 경로를 우선 사용한다.
- JSON 파일 접근은 `/data/...` 경로를 사용한다.
- 전화 링크, 외부 상세 링크, 유튜브 링크는 유지 가능하지만 목적과 위치가 분명해야 한다.

## 4. 수정 시 주의

- 공통 컴포넌트는 여러 페이지에 영향을 주므로 한 화면만 보고 수정하지 않는다.
- 주변 하위 디렉터리에 `AGENTS.md`가 있으면 그 규칙을 우선 따른다.
