# AGENTS.md

> `src` 이하 코드 작업 공통 규칙

## 1. 기본 원칙

- 현재 앱은 CRA 기반 React SPA다.
- 함수형 컴포넌트를 기준으로 작업한다.
- 큰 리팩터링보다 기존 패턴을 따라가는 수정이 우선이다.
- 전역 상태관리 도구를 새로 도입하지 않는다. 필요한 상태는 지역 상태로 유지한다.

## 2. 라우팅과 화면 구조

- 라우트 등록은 항상 `src/App.js`에서 한다.
- 상단 공통 프레임은 `Header1`, 하단 공통 프레임은 `Footer1`이다.
- 새 화면을 추가할 때는 기존 페이지처럼 `Box`, `CssBaseline`, `Container` 조합을 우선 고려한다.

## 3. 데이터 처리 규칙

- 현재 데이터 소스는 외부 API보다 `public/data/*.json` 정적 파일에 가깝다.
- JSON 구조를 바꾸면 `MainPage.js`, `DetailPage.js`, `categoryall.js` 소비 방식도 함께 확인한다.
- 새 외부 API가 필요하면 페이지 안에서 직접 호출을 늘리지 말고 공통 레이어를 먼저 만든다.

## 4. 반응형 규칙

- 모바일 대응은 기존처럼 `useMediaQuery` 패턴을 우선 따른다.
- 임계값은 주변 파일에서 쓰는 값과 맞춘다. 현재는 `768px`, `780px`, `835px` 등 파일별 문맥이 있다.
- 한쪽 화면만 수정하지 말고 모바일/데스크톱을 함께 점검한다.

## 5. 스타일 규칙

- 수정하는 파일의 기존 스타일 방식을 유지한다.
- MUI `sx`를 쓰는 파일은 `sx`를 우선 사용한다.
- CSS Module을 쓰는 파일은 같은 파일에서 CSS Module을 유지한다.
- 새 스타일 체계는 추가하지 않는다.

## 6. 한글과 인코딩 주의

- 일부 기존 텍스트는 터미널에서 한글이 깨져 보일 수 있다.
- 대규모 텍스트 수정 전 실제 에디터와 브라우저 렌더링을 기준으로 판단한다.
- 문자열만 대량 치환하는 작업은 신중하게 한다.
